# Projeto_Doceria 
Meu Primeiro Projeto Integrador
Este aqui é o registro do meu primeiro projeto completo integrando o Frontend com o Backend. Desenvolvi essa aplicação web para o gerenciamento de uma doceria, focando em deixar o sistema dinâmico e totalmente responsivo.

🛠️ O que eu usei no projeto:
Angular: Usei esse framework para construir toda a estrutura do site (SPA), organizando tudo em componentes e gerenciando as rotas e os serviços das páginas de forma inteligente.

TypeScript / JavaScript: Usei para criar toda a lógica das telas, fazer o site funcionar de verdade e consumir as APIs.

HTML5 & CSS3: Usei para estruturar páginas e criar o visual, focando em layouts modernos com Flexbox, Grid e gradientes personalizados.

JSON: Foi o formato que usei para organizar, enviar e receber os dados entre minhas telas e o servidor.

⚠️Nota Importante sobre o Status Atual

Um aviso rápido: o banco de dados e a API não estão ativos no momento .

Por conta disso, as funções de realização de cadastro e de adição de produtos no carrinho não irão processar o salvamento dos dados. O projeto está online neste link apenas como uma demonstração visual e de estrutura (Frontend) para mostrar o layout, a navegação entre as telas e a componentização que fiz com o Angular.

📌O que eu aprendi de principal:
Com esse projeto, consegui colocar em prática muita coisa que estudei. Aprendi a fazer o Angular conversar com um servidor usando o HttpClient para mandar e receber dados, a tratar requisições que demoram para responder e, principalmente, a quebrar a cabeça para resolver os problemas de implantação e colocar o site no ar integrado com uma API de fora.
